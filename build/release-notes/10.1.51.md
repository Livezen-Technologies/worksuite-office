# WorkSuite Office 10.1.51

## Improvements

- **A new ribbon in WorkSuite Project and WorkSuite Diagram.** Both apps now have a ribbon with icons, like the other WorkSuite editors. The main commands are large buttons, the others are small buttons beside them, and every group has a name.
  - **WorkSuite Project:** File, Task, Resource, Project and View tabs. Task has New task, Milestone, Auto Schedule, Indent, Link and % complete. Resource has the Workload view. Project has the calendar, Set Baseline and the status date.
  - **WorkSuite Diagram:** File, Home, Insert, Arrange and View tabs. Insert has From Table and Draft with AI. Arrange has alignment, auto-layout and grouping.
- In WorkSuite Project, the **Gantt Chart** and **Workload** buttons switch between the two views.
