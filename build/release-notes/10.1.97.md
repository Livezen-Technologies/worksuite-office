# WorkSuite Office 10.1.97

## New Features

- **Smart shapes in WorkSuite Diagram.** Shape data can now be a formula: type `=[Qty] * [Price]` as a value and the shape works out the total, and updates it when Qty or Price changes.
- **Text that shows data.** Put `{Name}` or `{Total}` in a shape's text and it shows that value, so labels stay right as data changes. Colours from data graphics follow formula results too.
