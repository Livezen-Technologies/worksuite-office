# WorkSuite Office 10.1.72

## New Features

- **Task calendars in WorkSuite Project.** Some work does not keep office hours. Select a task and set **Task › Calendar** to **Every day**, for things that carry on over weekends and holidays (concrete curing, a machine left running, a delivery in transit), or to **Mon–Sat** for a site that works Saturdays. The task's finish date, the tasks that wait for it and the project's finish all follow its own days.

## Known Issues

- Task calendars are not yet saved in Project XML files; the task uses the project calendar there.
