# WorkSuite Office 10.1.87

## New Features

- **Link data to your diagram in WorkSuite Diagram.** Choose **Insert › Link Data** and pick a CSV file or an Excel workbook, such as a list of process steps with their owner and status. Each row is matched to the shape with the same name and its columns become that shape's data; rows with no shape can be added as new shapes. Combine it with **Data Graphics** to colour the diagram by status. When the spreadsheet changes, choose **Refresh data** and pick the new copy.

## Known Issues

- Refresh data asks for the file again: a diagram cannot reopen a file on its own.
