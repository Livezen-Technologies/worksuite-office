# WorkSuite Office 10.1.33

## Improvements

- **A new opening screen.** WorkSuite Office opens with its logo flashing and then lit by a light sweep, with the WorkSuite Office name, on dark navy. The first window and the start page now look the same, so there is no jump between them. If your computer asks for reduced motion, the logo stays still.
- **One loading icon everywhere.** The start page, a tab that is opening a document and downloads all show the same animated logo, whose squares build up and come apart.

## Bug Fixes

- **The microphone settings link works.** When voice typing could not use the microphone, its link to the microphone settings did nothing. It now opens your computer's microphone privacy settings on Windows and macOS.
- **The licence link opens only the licence.** The command behind the About and Settings licence link could be made to open other files or programs on the computer. It now opens only WorkSuite Office's own licence.
