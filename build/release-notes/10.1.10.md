# WorkSuite Office 10.1.10

## New Features

- **One file explorer on Home.** Recent, My Drive, Shared with me, Starred and This computer are now tabs of one list, instead of two lists on top of each other. Recent shows the files you opened on this computer together with the files you recently opened in WorkSuite Drive, each only once.
- **One toolbar for every tab.** Search, file type, source, sort, list or grid, refresh and New or Open file, all in one row that stays in view as you scroll. Each tab keeps its own search, filters, sort and scroll position, and loads its files only when you open it.
- **New Create New cards.** Document, Spreadsheet, Presentation, PDF form and From template have new single-colour icons on plain cards.

## Improvements

- The whole start page follows the app's theme: Home, WorkSuite Drive, Templates, Clouds and Settings no longer use navy and blue backgrounds, selections or borders, in light, dark and custom themes.
- Changing the theme repaints the start page at once, and it opens in the theme you chose.
- Template pictures sit on plain surfaces and keep their own colours. A template without a picture shows its document type, and pictures show a placeholder while they load.
- In Settings the Accounts panel, the WorkSuite menu, Add account and the account badges use the theme's colours.

## Bug Fixes

- Custom dark themes are treated as dark themes on the start page.
- Text and buttons now pass the contrast check in the White, Night, Dark, Gray and Contrast Dark themes.

## Known Issues

- Uploading files is still done in Clouds › WorkSuite Drive; Upload in the Home file explorer takes you there.
- The loading screen stays WorkSuite navy in every theme.
