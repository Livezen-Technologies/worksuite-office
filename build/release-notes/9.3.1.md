## New Features
- Sign in with your WorkSuite account: in your browser, or with one click through WorkSuite Desktop when it is signed in on the same computer. Several accounts are supported.
- WorkSuite Drive on the home screen: Recent, Shared with me, Starred, My Drive and search, with a picture of each document.
- Drive documents open and save in WorkSuite Office; every save is a new version of the same Drive file, and Save as puts a copy in any Drive folder.
- New documents, spreadsheets and presentations go straight into a Drive folder.
- A WorkSuite item in the sidebar opens WorkSuite Desktop, or WorkSuite in your browser.
- "Open in WorkSuite Office" links (worksuiteoffice://) open the document in the app.

## Improvements
- The editor shows whether your changes are saved to WorkSuite Drive.
- On macOS, WorkSuite Office checks for updates with the WorkSuite Update Center.

## Known Issues
- The Windows and macOS builds are not code signed yet, so the system asks before opening them the first time.
- Copies installed before this version do not update themselves: install this version once.
