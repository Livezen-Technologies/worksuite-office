# WorkSuite Office 10.1.38

## New Features

- **WorkSuite Project.** Click **Project** on Home to plan work on a timeline. Add tasks, indent them under phases, set durations, dates, progress and owners, and see them in a Gantt chart beside the list. Link tasks so one starts when another finishes, and drag bars to move them or change how long they take. Save your plan, export it to Excel (XLSX) or CSV, and print it or save it as a PDF.

- **WorkSuite Diagram.** Click **Diagram** on Home to draw flowcharts, org charts and network diagrams. Drag shapes from the libraries, connect them with lines that stay attached when you move things, and line shapes up with the grid and guides. Change text, colours and sizes, use layers and pages, and save, export to PNG or SVG, or print.

- **Free to read, Pro to edit.** Anyone can open, read, print and export projects and diagrams. Creating and editing them is part of WorkSuite Office Pro; without it, a file opens read-only and tells you why, with a button to upgrade.

## Improvements

- **PDF editor on Home.** The PDF editor is back among the quick actions on Home.
- **Tidier Home.** The Local files and Connected cloud storage sections match the light and dark themes.

## Known Issues

- This is the first version of both apps. Working calendars, automatic scheduling, resources and Project XML files come later in WorkSuite Project; editing Visio drawings comes later in WorkSuite Diagram.
- A project or diagram opens in one tab per app for now, and saved files do not appear in Recent files yet.
