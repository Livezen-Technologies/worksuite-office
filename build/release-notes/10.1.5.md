# WorkSuite Office 10.1.5

## New Features

- **WorkSuite Local AI.** Voice typing, transcription, read aloud, writing help and suggestions that run on your computer. Models download from the Update Center when you turn a feature on.
- **New home screen.** Compact Create new cards, WorkSuite Drive files and recent files with search, filters, and list or grid views.
- **Clouds › WorkSuite Drive** is now a full file browser: folders, search, upload, download, share, Trash and more.
- **New Templates page** with filters, preview, favourites and organisation templates.
- **Document Preferences** in Settings › WorkSuite.
- **More legacy Sinhala fonts** for conversion, including DL-Sarala, FS-Kapila, Kumudu, Thara and Kandy.

## Improvements

- Update downloads show live progress on macOS and Windows; Windows checks the installer's signature before installing.
- The WorkSuite screens match WorkSuite Desktop's design in light, dark and high contrast.
- An account menu and a searchable organisation picker.

## Bug Fixes

- An expired WorkSuite session can be reconnected without removing the account.
- Two accounts on the same server no longer share an editor session.
- Clouds no longer shows an empty page with only a Connect button.
- Template thumbnails are no longer cut off.

## Known Issues

- The Thara, Padma, Kandy, Lankanatha and Lankapura maps are provisional; unmapped characters are listed before converting. Sri Lanka, SIN Walawe and VriSiNhala have no map yet.
- Local AI engines and models need to be published to the Update Center before the AI features can be turned on.
- Drive has no shared drives; folders in Trash are not listed.
