## New Features
- A Convert tab in the PDF Editor converts your PDF in one click: to Word (DOCX, DOTX, ODT, OTT or RTF), to images (PNG or JPEG, every page in one .zip file), to text (TXT or Markdown), to a web page (HTML) or to an e-book (EPUB or FB2). All formats opens the Save as dialog with every format.

## Improvements
- Feedback & Support, in the left bar of the editors, opens worksuitecloud.com.

## Bug Fixes
- The Sign in to WorkSuite dialog and button are readable in the dark themes.
- Signing in through WorkSuite Desktop or the browser no longer waits forever: WorkSuite Office says when WorkSuite Desktop is not installed or does not answer, and offers to try again or use the browser. Cancel and Esc end the sign-in.

## Known Issues
- Converting a PDF to Excel or PowerPoint, recognising the text of scanned PDFs (OCR) and saving a PDF as PDF/A are not in this version yet.
- The Windows and macOS builds are not code signed yet, so the system asks before opening them the first time.
- Copies older than 9.3.2 do not update themselves: install this version once.
