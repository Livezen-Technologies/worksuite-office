# WorkSuite Office 10.1.4

## New Features

- **Type Sinhala directly.** Sinhala Tools has four input modes (English, Sinhala Unicode, Sinhala legacy font and Smart Auto). Type Singlish and each word appears in Sinhala in the font you chose, including legacy fonts such as FM Abhaya and DL Manel. Press Ctrl+Shift+Y to turn it on or off.
- **Sinhala font picker** with samples and whether each font is installed.
- **Convert to legacy** now opens a dialog to choose the font, preview the result and convert in either direction.
- **New Settings › WorkSuite** with Accounts, WorkSuite Drive, Updates and About sections, and an add-account wizard.
- **New app icon and loading screen.**

## Improvements

- Accounts can be reconnected, switched, signed out or removed one at a time, and signing out keeps the account in the list.
- WorkSuite Drive shows a compact sign-in card and a connection summary.
- Settings are readable in dark mode and usable by keyboard.

## Bug Fixes

- About WorkSuite Office no longer opens empty; it shows the version and Livezen Technologies LLC.
- Add account, Sign in and other WorkSuite dialogs opened invisibly.
- Every Sinhala Tools button showed the same icon.
- Convert to legacy left the text in the wrong font, so it showed as Latin letters.
- The AI agent panel's "Connect an AI Model" screen was off-centre.

## Known Issues

- Only FM Abhaya, DL Manel and Kaputa have legacy character maps; FM Bindumathi is listed but can't be chosen yet. A full stop has no legacy glyph and is typed as-is.
- Sinhala and Tamil interface text is machine-translated and awaits native review.
- In spreadsheets and presentations, Sinhala typing doesn't set the font.
