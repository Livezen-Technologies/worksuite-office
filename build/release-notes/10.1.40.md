# WorkSuite Office 10.1.40

## New Features

- **Open and save Project XML in WorkSuite Project.** Plans saved as Project XML by Microsoft Project or other planning tools now open in WorkSuite Project: choose **Open** and pick the .xml file. Tasks, phases, durations, dates, progress, milestones, notes, date constraints, the links between tasks and the people assigned all come across. **Export Project XML** on the File tab saves your plan in the same format, so colleagues using other tools can open it. If a file holds something WorkSuite Project could not read, it tells you what when the file opens.

## Known Issues

- Costs, custom calendars, baselines and custom fields in a Project XML file are not read yet.
- Microsoft Project's own .mpp files cannot be opened yet; save them as Project XML (.xml) in Microsoft Project first.
