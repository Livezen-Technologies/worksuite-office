# WorkSuite Office 10.1.43

## Bug Fixes

- **Microsoft Project files.** Opening an `.mpp` file in WorkSuite Project now tells you how to bring it across instead of showing a confusing error: in Microsoft Project, choose **File › Save As**, pick **XML Format (*.xml)**, and open that file. Tasks, links, dates and people all come across.

## Known Issues

- WorkSuite Project does not open `.mpp` files directly; save them as Project XML first.
