# WorkSuite Office 10.1.56

## New Features

- **Earned value in WorkSuite Project.** Choose **Project › Earned Value** to see whether your project is on schedule and on budget at the status date. For each task, and for the whole project, it compares three amounts:
  - **Planned value:** the cost of the work that should be done by now.
  - **Earned value:** the cost of the work that is actually done.
  - **Actual cost:** what that work costs.

  Two numbers sum it up: **SPI** (schedule) and **CPI** (cost). Below 1 means behind schedule or over budget. The status bar always shows them for the whole project.
- **Baselines keep costs.** When you set a baseline, each task's cost and hours are saved with it, so earned value can measure against them.

## Known Issues

- Plans baselined before this version need **Project › Set Baseline** again before earned value can be measured.
- Actual cost is worked out from the current cost of the work done; there is no field yet for typing in what was really spent.
