# WorkSuite Office 10.1.28

## New Features

- **Help works offline.** Help is back in each editor's File menu. It opens the help pages included with the app, now in WorkSuite's name, so it works without internet.
- **Set up AI with no internet.** In Settings › AI Models, export a model on a computer that has it. Then import the `.wsmodel` file on a computer without internet: the model and the engine that runs it are installed together.
- **Sinhala fonts for every app.** Installing WorkSuite Office on Windows or Linux also installs Noto Sans Sinhala, Noto Serif Sinhala and Malithi Web for Word, browsers and other programs, not only the editors.

## Improvements

- Sinhala typing suggestions already come from the built-in word lists and work offline; the local AI suggestions are added when the AI service is running.

## Known Issues

- On macOS the Sinhala fonts are available in the editors only, not yet in other apps.
- An AI model exported before 10.1.28 does not include its engine. Export it again from a computer running 10.1.28.
- MCP connectors are not available on macOS yet, and OAuth sign-in for MCP servers is coming later (API keys work now).
