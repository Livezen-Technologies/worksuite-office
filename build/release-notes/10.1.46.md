# WorkSuite Office 10.1.46

## New Features

- **Part-time assignments in WorkSuite Project.** In the **Owner** column, add a percentage after a name, such as **Priya 50%**, when someone spends only part of their time on a task. The workload view adds up each person's share, so two half-time tasks on the same day are fine and only more than 100% is flagged as over-allocated. Part-time shares travel with Project XML files, to and from Microsoft Project.
