# WorkSuite Office 10.1.15

## New Features

- **Stamp PDF.** The PDF Tools tab has a new **Stamp** button. Add headers and footers (left, centre and right), page numbers ("Page 1 of 10"), Bates numbers with your prefix and start number, and a diagonal watermark such as CONFIDENTIAL, on every page or a page range. Header and footer text can include the page number, page count, Bates number, date and file name. The stamped copy is saved next to the PDF and opens in a new tab; the PDF itself is not changed.
- **PDF from images.** The new **From images** button makes a PDF from PNG and JPEG images, one page per image.

## Known Issues

- Stamp text can use Latin letters only for now; Sinhala and Tamil text is refused with a message.
- Stamp and From images need the WorkSuite Local AI service.
- Image watermarks, and saving PDF pages as TIFF, are not in this version.
