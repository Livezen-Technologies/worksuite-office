# WorkSuite Office 10.1.48

## New Features

- **More shapes in WorkSuite Diagram.** Four new libraries in the shape panel:
  - **Floor plan:** room, wall, door, window, stairs, round table, desk and chair, sofa.
  - **UML:** class, actor, use case, component, note, package.
  - **BPMN:** start event, end event, task, gateway, pool or lane.
  - **Cloud architecture:** virtual machine, container, function, queue, load balancer, object storage.

  Every shape is drawn by WorkSuite and exports to Visio (VSDX) like the others.

## Improvements

- Click a library's name to fold it open or closed. Flowchart, Basic, Org chart and Network start open.
