# WorkSuite Office 10.1.11

## New Features

- **PDF editor on Home.** The PDF form card in Create New is now PDF editor: it opens a PDF from your computer in the PDF editor.

## Improvements

- **Clearer main buttons.** New, Upload and Add account are a solid colour with a fine edge. In dark themes they are a crisp near-white instead of a washed-out grey, and a button you can't use yet looks muted instead of faded.
- **Reconnect matches its warning.** When an account's session has expired, Reconnect is amber like the "Session expired" badge beside it, with a refresh icon.
- **Tidier menus.** The account, New, file and filter menus have rounded rows, smaller text, inset dividers and single-colour icons, like the rest of WorkSuite.

## Bug Fixes

- The file icons in the New menu were cut off at the bottom.
