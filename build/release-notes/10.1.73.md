# WorkSuite Office 10.1.73

## New Features

- **Resource availability in WorkSuite Project.** Not everyone works full time on your project. On the **Resource Sheet**, set **Max units** for each person: 50% for someone who works half time, or 300% for a crew of three you plan as one. Over-allocation warnings, the Workload and Resource Usage views and **Level Resources** now measure against each person's real availability. It is kept when you exchange Project XML files with Microsoft Project.
