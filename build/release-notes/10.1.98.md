# WorkSuite Office 10.1.98

## New Features

- **Templates in WorkSuite Diagram.** Choose **File › From Template** to start from a ready-made page: a flowchart, a cross-functional flowchart with lanes, a BPMN process, an org chart, a project timeline, UML use case and class diagrams, a database diagram, a network diagram or a mind map.

## Improvements

- UML classes and database tables now show their name at the top and their fields listed underneath.
