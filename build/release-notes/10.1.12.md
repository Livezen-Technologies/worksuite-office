# WorkSuite Office 10.1.12

## New Features

- **Pages tab in the PDF editor.** Insert the pages of other PDFs, replace pages, duplicate pages, extract pages to a new PDF, and split a PDF by page ranges or every few pages. You can still drag thumbnails to reorder pages.
- **PDF tools on Home.** Merge PDFs, Split PDF and Extract pages open your PDF in the PDF editor and go straight to the tool. The matching AI Tools cards now do the same.

## Improvements

- **Your original stays as it was.** Extract and Split ask where to save each new PDF, then open the original PDF again, unchanged. Merge saves the result as a new PDF.

## Known Issues

- Extract and Split work on the PDF as it is saved, so save your changes first.
- Split shows one Save dialog for each part.
- The Pages tab needs plugins to be turned on, as text recognition (OCR) does.
