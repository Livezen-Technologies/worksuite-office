# WorkSuite Office 10.1.70

## New Features

- **Multiple baselines in WorkSuite Project.** **Project › Set Baseline** now lets you save up to eleven snapshots of your plan: Baseline, and Baseline 1 to 10. Keep the original plan, then save another after each approved change. Use **Compare with** to choose which snapshot the grey bars, earned value and the Project Overview measure against, and **Clear baseline** to remove one you no longer need.
