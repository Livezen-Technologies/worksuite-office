# WorkSuite Office 10.1.109

## New Features

- **Visio templates and macro drawings.** Open a Visio template (.vstx) to start a new diagram from it, or a macro-enabled drawing (.vsdm) to open its drawing. Save a diagram as a Visio template with **File › Visio template (VSTX)**.

## Known Issues

- Macros in .vsdm files are not run or kept.
- The older binary Visio files (.vsd, .vss, .vst) do not open; save them as .vsdx, .vssx or .vstx in Visio first.
