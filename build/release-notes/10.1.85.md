# WorkSuite Office 10.1.85

## New Features

- **Data graphics in WorkSuite Diagram.** Make your diagram show its data at a glance. After giving shapes shape data (such as Status or % done), choose **Insert › Data Graphics**: colour the shapes by a field with simple rules like `red if = "Late"; yellow if = "At risk"; green`, add a matching icon in each shape's corner, and show a number as a small bar under each shape. Change the data and the colours follow.

## Known Issues

- Data graphics are not written to Visio files; shapes keep their own colours there, and their shape data goes with them.
