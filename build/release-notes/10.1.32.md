# WorkSuite Office 10.1.32

## New Features

- **Sinhala voice typing, ready to use.** Click **Voice typing** on the **Sinhala Tools** tab and speak Sinhala: the text appears at the cursor, in the Sinhala font. The speech engine and the Sinhala speech model are part of WorkSuite Office, so there is nothing to download, install or set up, and what you say never leaves your computer.

## Bug Fixes

- **WorkSuite Office starts on Linux again.** 10.1.20 to 10.1.31 stopped as soon as they were opened, with "libicui18n.so.55: cannot open shared object file", because a library the app needs was missing from the package. It is included now, and every Linux build is checked so that this cannot ship again.
- **No more missing letters when typing Singlish quickly.** Typing fast, especially right after opening a document, could drop letters (*mama gedhara* became මම එදර) or leave a word in English letters. Every key is now kept and typed in order.
- **Singlish suggestions for words that start with ආ.** Typing a word with one "a" at the start, as most people do, now also suggests the word with ආ: *ayubowan* suggests ආයුබෝවන්.
- **The AI tools work on Linux.** In 10.1.20 the Local AI service crashed as soon as it started, so voice typing, transcription, read aloud and the AI writing tools did nothing. It starts now, and every Linux build checks that it does.
- **PDF Tools work again.** Protect, Stamp, Merge, From images, Form data, Sign, Page size and Versions in the PDF Editor stayed on "Please, wait..." and never made their file. They now finish in seconds.
- **Copies made by the PDF Tools open properly.** The protected, stamped, signed, cropped or converted copy opened in a new tab that said "Check your Internet connection". It now opens the file.
- **PDF dialogs read cleanly.** A long explanation at the top of Version history, Sign, Crop, Stamp, Protect, Split and the recognised text no longer runs over the rows below it.
- **OpenDocument spreadsheets saved as Excel open everywhere.** The list of number formats in the saved file was malformed, and stricter programs refused the file.
- **New document templates on Linux** are no longer copied to the top folder of the computer when xdg-user-dir is not installed.

## Improvements

- **New loading icons.** WorkSuite Office shows its own animated logo while it loads: on the start page, in a tab that is opening a document, and on downloads.
- **One AI tab.** The editors showed two tabs captioned AI. All the AI tools, WorkSuite's and the editors', are now in one AI tab.
- **Saved files say WorkSuite Office.** Word, Excel, PowerPoint, OpenDocument and PDF files now name WorkSuite Office as the program that made them, not ONLYOFFICE.

## Known Issues

- Sinhala voice typing is best with clear, read speech; casual or specialised speech has more mistakes (about 3 in 10 words need a correction there, against 2 in 10 for read speech). On slower computers the text comes when you stop rather than while you speak.

- On macOS the Sinhala fonts are added to your own account (~/Library/Fonts), not for every user on the Mac.
- An AI model exported before 10.1.28 does not include its engine. Export it again from a computer running 10.1.28 or later.
- MCP connectors are not available on macOS yet, and OAuth sign-in for MCP servers is coming later (API keys work now).
