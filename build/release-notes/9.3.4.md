## New Features
- Signing in to WorkSuite through the browser now has a fallback: if WorkSuite Office keeps waiting after you continue in the browser, copy the code the browser page shows and choose Paste the sign-in code in WorkSuite Office.

## Improvements
- Continue as is now an account card, with your initials, name, organisation and server. Sign in to WorkSuite beside it is an outlined button of the same height.

## Bug Fixes
- Signing in through the browser no longer waits forever when the browser does not open WorkSuite Office again afterwards.

## Known Issues
- The browser page shows the code to copy once app.worksuite.lk runs the matching server update.
- Converting a PDF to Excel or PowerPoint, recognising the text of scanned PDFs (OCR) and saving a PDF as PDF/A are not in this version yet.
- The Windows and macOS builds are not code signed yet, so the system asks before opening them the first time.
- Copies older than 9.3.2 do not update themselves: install this version once.
