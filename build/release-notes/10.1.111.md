# WorkSuite Office 10.1.111

## New Features

- **Linked subprojects.** A plan you bring in with **Insert › Project** stays linked to its file (marked ⧉). **Refresh subproject** brings in a newer copy of that file, **Save subproject** writes its tasks back out as a .wsproj, and **Unlink subproject** keeps the tasks without the link. Subprojects are kept in Project XML files as Microsoft Project's subprojects.

## Known Issues

- Refreshing asks you to choose the file again; links to tasks inside the subproject are removed on refresh, links to the subproject's summary stay.
