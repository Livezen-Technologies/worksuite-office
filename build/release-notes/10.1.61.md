# WorkSuite Office 10.1.61

## New Features

- **Task Usage and Resource Usage in WorkSuite Project.** Choose **View › Task Usage** to see how many hours each task needs each week, and who does them. Choose **View › Resource Usage** to see each person's hours per week across all their tasks. Weeks in which someone has more work than fits in a day are shown in red, so you can spot overload at a glance.
