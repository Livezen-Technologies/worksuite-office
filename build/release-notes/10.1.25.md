# WorkSuite Office 10.1.25

## New Features

- **AI & MCP Connectors in Settings.** Add AI providers (OpenAI-compatible services, Ollama, custom endpoints), test them, see their models and choose the default provider and model the Office AI features use. Connect MCP servers, local (a command on this computer) or remote (Streamable HTTP), test them and see their tools, resources and prompts, with an activity log.
- **You approve every MCP action.** Running an MCP tool always asks first and shows what it will do; you can allow a tool for a server permanently and take that back in Settings. Keys are kept in Windows Credential Manager (libsecret on Linux), never in the settings file.
- **A Home page that gets you started.** Quick actions for Document, Spreadsheet, Presentation, Open file and From template; Pinned files, Local files (your recent folders) and Connected cloud storage beside your recent files.
- **A Home tab and a WorkSuite title bar.** The title bar shows the WorkSuite Office icon and name, the first tab is Home with a house icon, and the window frame follows the app's light or dark theme on Windows 10 and 11.

## Improvements

- When there are more tabs than fit, an "All tabs" menu lists them all.
- The files you had open come back the next time you start WorkSuite Office.
- Tab spacing follows your display scaling.

## Bug Fixes

- The same file opened twice when its path was written with different letter case or slashes; it now switches to the open tab.

## Known Issues

- MCP connectors are not available on macOS yet, and OAuth sign-in for MCP servers is coming later (API keys work now).
- The editors' AI assistant can't use MCP tools yet; tools can be tested from Settings.
- "Home" and "All tabs" are in English in every language until they are translated.
