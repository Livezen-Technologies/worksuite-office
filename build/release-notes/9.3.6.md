## Improvements
- The start page scrolls as one: the WorkSuite Drive list shows its first ten files, with Show all for the rest, instead of a second scrollbar inside the page.

## Bug Fixes
- Files opened from WorkSuite Drive no longer show under On this computer. They are in WorkSuite Drive's Recent.

## Known Issues
- Signing in continues by itself, and Drive documents open without the WorkSuite web header, once app.worksuite.lk runs the matching server update.
- Converting a PDF to Excel or PowerPoint, recognising the text of scanned PDFs (OCR) and saving a PDF as PDF/A are not in this version yet.
- The Windows and macOS builds are not code signed yet, so the system asks before opening them the first time.
- Copies older than 9.3.2 do not update themselves: install this version once.
