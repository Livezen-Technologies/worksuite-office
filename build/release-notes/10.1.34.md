# WorkSuite Office 10.1.34

## New Features

- **Remove hidden information from a PDF.** On the PDF Tools tab, **Remove hidden info** saves a copy without the information you cannot see on the page but someone could still find in the file: the author and other document details, scripts, attached files, comments and highlights, page thumbnails and data left by other programs. Links and form fields stay, and older saved versions hidden inside the file are dropped too. When it is done, WorkSuite Office tells you what it removed. Your original PDF is not changed.

- **Check whether a PDF meets PDF/A.** The **PDF/A** button on the Convert tab now has a menu: **Save as PDF/A-2** as before, and **Check PDF/A**. The check looks at the main PDF/A-2 requirements, such as embedded fonts, the colour profile, no scripts and printable comments, and tells you in plain words what is missing. It checks how the file is put together, not every detail of the page content.

- **Compare two versions of a PDF.** On the PDF Tools tab, **Compare** asks for the earlier version and opens a copy of this PDF with the differences marked: added words are highlighted, and removed or replaced text is shown in notes, in Sinhala, Tamil or any other language. Text that only moved to another line or page does not count as a change. If the text is the same, WorkSuite Office tells you instead.

## Bug Fixes

- **Protect explains PDF/A.** Adding a password to a PDF/A file failed with an internal error. WorkSuite Office now explains that PDF/A files cannot have a password.

## Known Issues

- Compare looks at the text only: changes to pictures, colours or layout are not shown. Scanned PDFs need their text recognised first.

- Layers in a PDF are kept as they are, including hidden ones. The copy tells you when a PDF has layers.
- A few PDFs have parts WorkSuite Office cannot read. For those, no copy is saved, so you never get a damaged file.
