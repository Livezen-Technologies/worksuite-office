# WorkSuite Office 10.1.80

## Improvements

- **Interim plans and task calendars travel with Project XML.** When you save a WorkSuite Project plan as Project XML, your interim plans go with it as Microsoft Project's Start1–Finish1 to Start10–Finish10 fields, and tasks on the Every day or Mon–Sat calendar keep their calendar. Opening a Project XML file brings both back.

## Known Issues

- Split tasks are not yet saved in Project XML files; the task keeps its duration there.
- A task calendar from Microsoft Project other than every day or Monday to Saturday is read as the project calendar.
