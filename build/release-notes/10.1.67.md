# WorkSuite Office 10.1.67

## Improvements

- **Custom fields now travel with Project XML.** When you save a WorkSuite Project plan as Project XML, your custom fields go with it as Microsoft Project's Text, Number, Date and Flag fields, keeping their names. Opening a Project XML file from Microsoft Project brings its Text, Number, Date and Flag fields in as custom fields, values and all.

## Known Issues

- Project XML holds up to 30 text, 20 number, 10 date and 20 yes/no fields; any beyond those are left out of the file.
