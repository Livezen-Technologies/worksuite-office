# WorkSuite Office 10.1.68

## New Features

- **Progress line in WorkSuite Project.** Set a status date, then tick **Project › Progress line**. A red line runs down the Gantt chart from the status date and bends out to how far each task has got. Where it points left, that task is behind; where it points right, the task is ahead. It is a quick way to see at a glance which work needs attention.
