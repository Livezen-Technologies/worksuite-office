# WorkSuite Office 10.1.54

## New Features

- **Work and task types in WorkSuite Project.** A new **Work** column shows how many hours each task takes. That's its duration times the people on it, at 8 hours a day. You can also type the hours yourself.
  - The task type, under **Task › Type**, decides what changes when you change something else:
    - **Fixed units** (the default): change the duration and the work follows; change the work and the duration follows.
    - **Fixed work:** the hours stay the same; make the task longer and each person's share goes down.
    - **Fixed duration:** the dates stay the same; add hours and each person's share goes up.
  - Tick **Effort driven** so that adding a person makes the task shorter. The same hours are shared out.
- Task types, effort driven and work are kept in Microsoft Project XML files.

## Bug Fixes

- Project XML files saved by WorkSuite Project marked every task as "fixed duration" in Microsoft Project. Each task now keeps its own type.
