# WorkSuite Office 10.1.113

## New Features

- **Sinhala Tools in Project and Diagram.** A Sinhala Tools tab, as in the document editors: Singlish typing in shape text, labels and task names; legacy Sinhala font text (FM Abhaya, DL Manel, Kaputa, Lastech, Kandy) converted to Unicode in the selected shapes or tasks; and badly formed Sinhala put right.
