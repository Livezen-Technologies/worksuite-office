# WorkSuite Office 10.1.55

## New Features

- **Costs in WorkSuite Project.** Open **Resource › Resource Sheet** to see everyone on your plan. Type each person's **rate per hour** and, for things paid per job (movers, a hall), a **cost per use**. Each person's total hours and cost are shown beside them.
- **Cost and fixed cost on every task.** The new **Cost** column shows what each task costs: its hours at each person's rate, plus any cost per use and the task's own **Fixed cost**, which you can type in. Summary tasks add up their tasks, and the status bar shows the cost of the whole project.
- Rates, costs per use and fixed costs are kept in Microsoft Project XML files.

## Known Issues

- Amounts have no currency symbol yet, and one rate applies to a person for the whole project.
