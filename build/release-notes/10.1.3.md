# WorkSuite Office 10.1.3

## Changes

- **The app wears the WorkSuite mark.** The icon is WorkSuite's across every
  place one appears: the Windows program and its window, the macOS app, the
  Linux desktop icons and the update service. The icons for each document
  type are unchanged.
- **A loading screen while the app starts.** The start page now shows the
  WorkSuite loading animation — the name with the pages and a progress bar —
  instead of a turning circle. Reduced motion shows it still.
- **Waiting looks like WorkSuite.** While the app is busy it shows the brand's
  four squares, dimming one after another, the same mark as the web app and
  the desktop app.

These are the same binaries as 10.1.2 with the branding above; nothing else
in the editors changed.
