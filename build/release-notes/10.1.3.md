# WorkSuite Office 10.1.3

## Changes

- **The app wears the WorkSuite mark.** The icon is WorkSuite's across every
  place one appears: the Windows executable and window, the macOS app, the
  Linux desktop entry, and the update daemon. The per-file-format icons on a
  document are unchanged.
- **A loading screen while the app starts.** The start page now shows the
  WorkSuite loading animation — the wordmark with the pages and a progress
  bar — instead of a turning circle. Reduced motion shows it still.
- **Waiting looks like WorkSuite.** The small in-app spinners are the brand's
  four squares, dimming one after another, the same mark as the web app and
  the desktop app.

These are the same binaries as 10.1.2 with the branding above; nothing else
in the editors changed.
