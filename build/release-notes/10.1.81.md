# WorkSuite Office 10.1.81

## New Features

- **Insert a project into another in WorkSuite Project.** Choose **Task › Project** and pick a plan, a WorkSuite Project file or a Project XML file from Microsoft Project. It comes in as one summary task, with all its tasks, links, people and custom fields, so you can build a master plan from the plans of each team. Link its tasks to yours, then choose **Auto Schedule**.

## Known Issues

- An inserted project is a copy: later changes to its own file do not flow into the master plan.
