# WorkSuite Office 10.1.26

## Bug Fixes

- 10.1.25 could not be built for Windows and Linux. 10.1.26 is the same release with that fixed: the AI & MCP Connectors in Settings, the new Home page, the WorkSuite title bar with a Home tab, the All tabs menu and reopening the last session's files. See the 10.1.25 notes for details.

## Known Issues

- MCP connectors are not available on macOS yet, and OAuth sign-in for MCP servers is coming later (API keys work now).
- The editors' AI assistant can't use MCP tools yet; tools can be tested from Settings.
- "Home" and "All tabs" are in English in every language until they are translated.
