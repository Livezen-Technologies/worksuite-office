## Improvements
- The account switcher and New beside WorkSuite Drive are drawn in your theme's colours: the switcher is an outlined chip with your name, organisation and server, and New is the accent button, as tall as the search box.
- Continue as through WorkSuite Desktop waits two minutes for you to confirm in WorkSuite Desktop, as long as the sign-in code lives.

## Bug Fixes
- Signing in through the browser, or with Continue as through WorkSuite Desktop, no longer keeps you waiting when the link back to WorkSuite Office does not arrive. WorkSuite Office now collects the sign-in from the server while it waits and continues by itself.
- The account switcher and New beside WorkSuite Drive no longer show white with light text in dark themes.

## Known Issues
- Signing in continues by itself once app.worksuite.lk runs the matching server update (Auth 2.4.0); until then it waits for the link back, and Paste the sign-in code still works.
- Converting a PDF to Excel or PowerPoint, recognising the text of scanned PDFs (OCR) and saving a PDF as PDF/A are not in this version yet.
- The Windows and macOS builds are not code signed yet, so the system asks before opening them the first time.
- Copies older than 9.3.2 do not update themselves: install this version once.
