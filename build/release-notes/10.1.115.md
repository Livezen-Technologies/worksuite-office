# WorkSuite Office 10.1.115

## Bug Fixes

- **Activation in release builds.** The WorkSuite licence key is now built into WorkSuite Office, so a WSO-… key from your purchase activates Pro without any extra setup.

## Known Issues

- Activation works only in builds made after the licence key is set in the build settings (the WS_LICENSE_PUBLIC_KEYS repository variable). A build made without it says so in its log, and accepts keys only when set up with WS_AI_LICENSE_KEYS.
