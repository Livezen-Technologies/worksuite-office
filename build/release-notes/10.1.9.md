# WorkSuite Office 10.1.9

## Bug Fixes

- **WorkSuite Office opens again on macOS 26.** Versions 10.1.5 and 10.1.6 quit as they started ("WorkSuite Office quit unexpectedly") on macOS 26, because the menu's Check for Updates item was set up in a way macOS 26 no longer allows. It now opens normally, and Check for Updates works as before.

## Improvements

- On macOS the app's process is named **WSOffice** instead of ONLYOFFICE, in Activity Monitor, Force Quit and crash reports. Your settings and updates carry over.
- The editor window's placeholder title says WorkSuite Office.

## Known Issues

- On Windows and Linux the process names are unchanged (DesktopEditors and desktopeditors).
