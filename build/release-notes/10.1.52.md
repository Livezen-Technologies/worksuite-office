# WorkSuite Office 10.1.52

## New Features

- **Your diagrams in WorkSuite Drive.** Diagrams you saved to WorkSuite Drive from WorkSuite Diagram (`.wsdiagram`) now show up in the start page's Drive list. Click **Open** and the diagram opens in WorkSuite's Diagram app in your browser. There you and your team can work on it together, and it stays the same file in Drive.

## Known Issues

- Opening needs a WorkSuite server with the Diagram update (Diagram 1.4.0). On an older server the browser says it cannot open that file.
- WorkSuite Project plans (`.wsproj`) in Drive are not listed yet.
