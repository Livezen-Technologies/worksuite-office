# WorkSuite Office 10.1.13

## New Features

- **PDF Tools tab in the PDF editor.** The Pages tab is now called PDF Tools and has a new **Merge** button: choose other PDFs to add at the end, then save the result as a new PDF. Insert from file, Replace, Duplicate, Extract and Split are in the same tab.

## Improvements

- The PDF tools are no longer shown on the Home screen; open a PDF with the **PDF editor** card and use the PDF Tools tab.

## Known Issues

- Extract and Split ask you to save the PDF first, and Split asks for a file name for each part.
- The PDF Tools tab needs plugins to be turned on, as text recognition (OCR) does.
