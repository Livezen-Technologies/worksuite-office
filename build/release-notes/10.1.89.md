# WorkSuite Office 10.1.89

## New Features

- **Containers in WorkSuite Diagram.** Select some shapes and choose **Insert › Container** to draw a titled box around them, such as "Intake" or "Finance team". Drag the container and everything in it comes along.
- **Callouts.** Select a shape and choose **Insert › Callout** to add a note pointing at it. The pointer follows the shape wherever you move it.
